# Licensing

Spool is published under two licenses. Each directory carries its own
`LICENSE` file, and each package manifest names its license.

| Component | Paths | License |
| --- | --- | --- |
| Server, control plane, storage engine, protocol, runner agent, test harness, dashboard | `crates/`, `web/` | [FSL-1.1-ALv2](LICENSES/FSL-1.1-ALv2.md) |
| Deployment, documentation, reference, scripts | `deploy/`, `docs/`, `reference/`, `scripts/` | [Apache-2.0](LICENSES/Apache-2.0.txt) |

The Functional Source License lets you read, audit, modify and run the
software for any purpose other than offering a competing product or service.
Each released version becomes available under Apache-2.0 on the second
anniversary of its release.

Anything not covered by a more specific `LICENSE` file is Apache-2.0.

Third-party components that are redistributed with the product are listed in
[NOTICE](NOTICE) with their licenses.
